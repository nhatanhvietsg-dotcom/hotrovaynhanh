Quản trị nội dung website

Đăng nhập bằng tài khoản GitHub có quyền ghi vào kho nhatanhvietsg-dotcom/hotrovaynhanh.

Cách sửa và xuất bản

  1. Mở “Nội dung website” → “Trang chủ, ảnh và liên hệ”.
  2. Mở khu vực muốn sửa; thay chữ trong ô Nội dung hoặc chọn ảnh mới trong mục Ảnh trên website.
  3. Kiểm tra khung xem trước. Khung này chỉ xem, không gửi yêu cầu tư vấn.
  4. Bấm Xuất bản (Publish). Thay đổi được lưu trên GitHub; Netlify sẽ triển khai tự động. Chờ bản triển khai hoàn tất rồi tải lại trang công khai.

Email liên hệ công khai và hộp thư nhận lead được cấu hình riêng. Thay email tại đây không thay hộp thư nhận lead.

Kết nối đăng nhập lần đầu

Nếu đăng nhập báo chưa cấu hình nhà cung cấp, chủ tài khoản cần kết nối GitHub OAuth với Netlify một lần:

  1. Tại GitHub → Settings → Developer settings → OAuth Apps → New OAuth App. Tên: Hỗ Trợ Vay Vốn CMS. Homepage URL: https://hotrovaynhanh.com. Authorization callback URL: https://api.netlify.com/auth/done.
  2. Tạo Client Secret trong GitHub. Giữ kín giá trị này; không gửi qua chat hoặc đưa vào mã nguồn.
  3. Trong Netlify, dự án hotrovay → Project configuration → Security → OAuth → Authentication Providers → Install Provider → GitHub.
  4. Nhập Client ID và Client Secret trực tiếp tại Netlify, lưu rồi trở lại /admin/ để đăng nhập. Kiểm tra tài khoản và quyền trước khi bấm cấp quyền.
